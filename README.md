# گوجه‌پران 🍅

بازی تحت وب با دوربین گوشی: روی هر جای دنیای واقعی بزن تا گوجه نامحدود پرتاب شود و همان‌جا له شود.

- دوربین عقب و جلو قابل تعویض است.
- پرتاب نامحدود، با انیمیشن چرخش، پاشش ذرات، دانه، پوست و چکه‌های آب گوجه.
- صدای له‌شدن با WebAudio ساخته می‌شود؛ بدون فایل صوتی.

## حریم خصوصی — مهم

دوربین فقط پس‌زمینهٔ زندهٔ همین بازی است. هیچ ویدیو یا عکسی ضبط نمی‌شود، ذخیره نمی‌شود و برای هیچ‌کس ارسال نمی‌شود. در کد هیچ MediaRecorder، هیچ آپلود و هیچ توکنی وجود ندارد.

## اجرا

فایل `index.html` را روی HTTPS باز کن (مثل GitHub Pages) و دکمهٔ شروع با دوربین عقب یا جلو را بزن.
